# タスク４：RESTful API をデプロイする

Amazon API Gateway を使用して、前のモジュールで構築した Lambda 関数を RESTful API として公開します。この API はパブリックインターネットでアクセス可能になります。

最初のステップでデプロイした静的ウェブサイトには、このモジュールで構築する API と連携するように設定済みのページが既にあります。`/ride.html` のページには、ユニコーンに乗ることを要求するシンプルなマップベースのインターフェイスがあります。`/signin.html` ページを使用した認証後、ユーザーはマップ上のポイントをクリックし、右上隅の「Request Unicorn」ボタンを選択して、乗る場所を選択することができます。

## 手順

### REST API の作成

1. Amazon API Gateway コンソールで、「API の作成」を選択します。
2. 「REST API」で「構築」を選択します。
3. 「新しい API」を選択し、「API 名」に `WildRydes` と入力します。
4. 「エンドポイントタイプ」ドロップダウンで「エッジ最適化」を選択します。
5. 「Security policy」では `TLS_1_0` を選択し、「API の作成」を選択します。

### Cognito ユーザープールオーソライザーの作成

Amazon API Gateway は、Amazon Cognito ユーザープールから返される JSON ウェブトークン（JWT）を使用して API 呼び出しを認証します。ユーザープールを利用できるように、API のオーソライザーを作成します。

6. 先ほど作成した WildRydes API の左側のナビゲーションペインで、「オーソライザー」を選択します。
7. 「新しいオーソライザーの作成」を選択します。
8. オーソライザーの「名前」フィールドに `WildRydes` と入力します。
9. 「タイプ」として「Cognito」を選択します。
   - Cognito ユーザープールの「リージョン」ドロップダウンで、使用中のリージョンを選択します。
   - Cognito ユーザープールの「名前」フィールドから `WildRydes` を選択します。
10. 「トークンのソース」に `Authorization` と入力し、「作成」を選択します。

### リソースとメソッドの作成

API 内に新しいリソースを作成し、そのリソース用の POST メソッドを作成します。前のステップで作成した `RequestUnicorn` 関数による Lambda プロキシ統合を使用するようにメソッドを設定します。

11. WildRydes API の左側のナビゲーションペインで、「リソース」を選択します。
12. 「アクション」ドロップダウンから、「リソースの作成」を選択します。
13. 「リソース名」に `ride` と入力すると、リソースパス `/ride` が自動的に作成されます。
14. 「API Gateway CORS を有効にする」のチェックボックスをオンにし、「リソースの作成」を選択します。
15. 新しく作成した `/ride` リソースが選択された状態で、「アクション」ドロップダウンから「メソッドの作成」を選択します。
16. 「オプション」の下に表示される新しいドロップダウンから「POST」を選択し、チェックマークアイコンを選択します。
    - 統合タイプとして「Lambda 関数」を選択します。
    - 「Lambda プロキシ統合の使用」のチェックボックスをオンにします。
17. 使用中のリージョンを選択し、「Lambda 関数」に `RequestUnicorn` と入力します。「保存」を選択します。

### オーソライザーの設定

18. 「メソッドリクエスト」カードを選択します。「編集」ボタンを押下し、「認可」ドロップダウンの一覧から WildRydes Cognito ユーザープールオーソライザーを選択し、保存します。

### API のデプロイ

19. 「アクション」ドロップダウンリストで「API のデプロイ」を選択します。
20. 「デプロイステージ」ドロップダウンリストから「新しいステージ」を選択します。
    - 「ステージ名」に `prod` と入力します。
    - 「デプロイ」を選択します。
21. 「呼び出し URL」をコピーします。これは次のステップで使用します。

### 設定ファイルの更新

22. ウェブサイトの `/js/config.js` ファイルを更新し、作成したステージの呼び出し URL を含めます。ローカルマシンで `js` フォルダに移動し、任意のテキストエディタで `config.js` ファイルを開きます。
23. 前の手順で Amazon API Gateway コンソールからコピーした呼び出し URL を `config.js` ファイルの `invokeUrl` 値に貼り付けます。ファイルを保存します。
24. 更新した `config.js` ファイルを追加、コミット、Git リポジトリにプッシュすると、自動的に Amplify コンソールにデプロイされます。

### 動作確認

25. `ride.html` ファイルの ArcGIS JS バージョンを 4.3 から 4.6 に次のように更新します（2 か所の変更部分は離れた箇所にあります）。
    ```html
    <script src="https://js.arcgis.com/4.6/"></script>
    <link rel="stylesheet" href="https://js.arcgis.com/4.6/esri/css/main.css">
    ```
26. 変更したファイルを保存します。ファイルを追加、コミット、Git リポジトリにプッシュすると、AWS Amplify コンソールに自動的にデプロイされます。
27. デプロイ完了後、ウェブサイトの `/ride.html` にアクセスします。マップがロードされたら、マップ上の任意の場所をクリックして、ピックアップ場所を設定します。
28. マップ右上の「Request Unicorn」を選択します。右のサイドバーの通知で、ユニコーンが向かっていることが表示され、続いてピックアップ場所にユニコーンのアイコンが移動します。

> DynamoDB のテーブルにも項目が追加されていることを確認します。
