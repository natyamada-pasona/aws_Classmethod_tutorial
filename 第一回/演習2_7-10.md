## タスク7：Lambda 関数作成②（DynamoDB 書き込み用）

DynamoDB に投稿を書き込む関数を作成します。

① Lambda のコンソールを表示し「関数の作成」を選択します。

② 以下の設定で関数を作成します。
- 関数名：`DynamoDBWriteFunction`
- ランタイム：Python 3.12
- 実行ロール：基本的な Lambda 権限

③ さらに DynamoDB に書き込むための以下の権限を追加します。
- `AmazonDynamoDBFullAccess`

④ 関数のコードは以下の通りです。デプロイも忘れずに実行します。

```python
import json
import uuid
import boto3

dynamodb = boto3.resource("dynamodb")
table = dynamodb.Table("ArticlesTable")

def lambda_handler(event, context):
    body = json.loads(event["body"])
    item = {
        "id": str(uuid.uuid4()),       # ← 必須
        "title": body["title"],
        "content": body["content"],
        "shared": body["shared"]        # ← 必須（bool）
    }
    table.put_item(Item=item)

    return {
        "statusCode": 200,
        "headers": {
            "Access-Control-Allow-Origin": "*",
            "Access-Control-Allow-Headers": "Content-Type",
            "Access-Control-Allow-Methods": "OPTIONS,POST"
        },
        "body": json.dumps({
            "message": "Article created successfully!"
        })
    }
```

## 【オプション演習】1：抽選機能追加

ナレッジ共有促進化のため、共有設定をオンにして投稿すると抽選が実行できる機能を追加します。

① 抽選用 Lambda 関数を作成します。
- 関数名：`LotteryFunction`
- ランタイム：Python 3.12
- 実行ロール：既存の基本 Lambda ロール

② コードは以下の通りです。

```python
import json
import random

def lambda_handler(event, context):
    detail = event["detail"]
    # 30%で当選
    win = random.random() < 0.3

    result = {
        "articleId": detail["id"],
        "winner": win
    }

    print("Lottery result:", result)

    return {
        "statusCode": 200,
        "body": json.dumps(result)
    }
```

③ EventBridge に抽選ルールを追加します。ルール作成画面で以下の通り設定します。
- 名前：`lottery-rule`
- イベントバス：`bookmarks-bus`
- ルールタイプ：イベントパターン
- ターゲットタイプ：Lambda
- 関数：`LotteryFunction`

イベントパターン：

```json
{
  "detail-type": ["ArticleShared"],
  "detail": {
    "shared": [true]
  }
}
```

④ 抽選結果取得用 API を作成します。既存の API Gateway 画面を表示し、`GET /lottery-result` を追加します。
- 統合先：`LotteryFunction`

⑤ 新規 HTML ファイルを作成し、以下を入力します。

```html
<!DOCTYPE html>
<html>
<body>
  <h2>Create Article</h2>
  <input id="title" placeholder="title"><br>
  <textarea id="content"></textarea><br>
  <label>
    <input type="checkbox" id="shared">
    Share this article
  </label><br><br>
  <button onclick="send()">Submit</button>
  <h3 id="result"></h3>

  <script>
    async function send() {
      const res = await fetch(
        "https://XXXX.execute-api.ap-northeast-1.amazonaws.com/articles",
        {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({
            title: title.value,
            content: content.value,
            shared: shared.checked
          })

      );

      if (!res.ok) {
```
