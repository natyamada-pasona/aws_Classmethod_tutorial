## タスク5：EventBridge 設定

Lambda が「Bookmark が投稿された」という事実を EventBridge に送信し、EventBridge のルールでその事実を検知したら Step Functions（ワークフロー）を起動できる状態にします。EventBridge では演習専用のカスタムイベントバスを作成します。

① EventBridge の画面を表示し、左側のメニューから「イベントバス」を選択、カスタムイベントバス欄の「イベントバスを作成」をクリックします。

② 名前を `bookmarks-bus` に設定し作成します。

③ Lambda の編集をします。Lambda 関数に設定されている既存ロールに以下インラインポリシーを追加し、Lambda が EventBridge に PutEvents できるよう設定します。

### インラインポリシー

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": "events:PutEvents",
      "Resource": "arn:aws:events:ap-northeast-1:*:event-bus/bookmarks-bus"
    }
  ]
}
```

④ Lambda コードも以下を編集し、EventBridge へ送信できるようにします。

> ※ バス名は作成した EventBridge カスタムイベントバス名に置き換えること。

### Lambda 関数コード（EventBridge 送信対応版）

```python
import json
import boto3
from botocore.exceptions import ClientError

dynamodb = boto3.resource("dynamodb")
table = dynamodb.Table("BookmarksTable")

# ★追加: EventBridge クライアント
eventbridge = boto3.client("events")

def lambda_handler(event, context):
    body = json.loads(event["body"])
    content = body["content"]
    title = body.get("title", "")
    shared = body.get("shared", False)

    try:
        table.put_item(
            Item={
                "content": content,
                "title": title,
                "shared": shared
            },
            ConditionExpression="attribute_not_exists(content)"
        )
    except ClientError as e:
        if e.response["Error"]["Code"] == "ConditionalCheckFailedException":
            return {
                "statusCode": 409,
                "body": json.dumps({
                    "message": "Duplicate bookmark"
                })
            }
        raise

    # ★保存成功後のみ、shared=true ならイベント送信
    if shared:
        response = eventbridge.put_events(
            Entries=[
                {
                    "EventBusName": "バス名",
                    "Source": "bookmark.app",
                    "DetailType": "BookmarkShared",
                    "Detail": json.dumps({
                        "content": content,
                        "title": title,
                        "shared": shared
                    })
                }
            ]
        )
        # ★追加: EventBridge 送信成功ログを CloudWatch Logs 出力
        print("Event sent to EventBridge")
        print("EventBridge response:", response)

    return {
        "statusCode": 200,
        "headers": {
            "Access-Control-Allow-Origin": "*",
            "Access-Control-Allow-Headers": "Content-Type",
            "Access-Control-Allow-Methods": "OPTIONS,POST"
        },
        "body": json.dumps({
            "message": "Bookmark created successfully!"
        })
    }
```

⑤ EventBridge ルールを作成します。これは受け取ったデータを誰に渡すのかを決めるためです。EventBridge 画面の左側メニューから「ルール」を選択します。

⑥ 「イベントバスを選択」から作成済のバスに切り替え、「ルールを作成」ボタンをクリックします。

> ※ ここで選択するバスは、Lambda 関数コード内の `"EventBusName": "バス名"` と一致している必要があります。

ルール名に `BookmarkCreatedRule`、カスタムバスを確認し、「次へ」をクリックします。

⑦ イベントは「その他」を選択、イベントパターンは「カスタムパターン（JSON エディタ）」に変更し、以下の JSON を入力し、「次へ」をクリックします。

```json
{
  "source": ["bookmark.app"],
  "detail-type": ["BookmarkShared"]
}
```

⑧ ターゲットは未作成のため、ダミーで Lambda 関数を選択し、任意の関数に設定しルール作成を完了します。（ターゲットは後で修正）

⑨ ここまでの動作確認をします。アプリを起動し、データを投入します。Lambda の CloudWatch Logs を確認し、「Event sent to EventBridge」「EventBridge response」とログが生成されていることを確認します。

## タスク6：Step Functions（承認ワークフロー）作成

EventBridge に「BookmarkCreated」という事実が伝わり、次に業務フローを Step Functions によって制御します。条件によって処理を分岐し、人の手による承認作業および結果確定を実現し、流れを可視化します。

① Step Functions の画面を表示し、これまで利用していたリージョンになっていることを確認します。

② 左側のメニューから「ステートマシン」を選択、「ステートマシンの作成」ボタンをクリックします。

③ 「空白から作成」を選び、任意の名前を入力、タイプは「標準」を選択し続行します。

④ 「デザインモード」になっている画面を「コード」に切替、既存コードを削除し、以下 JSON データを入力し、作成します。

> ※ コード内で指定している Lambda 関数 `CheckDuplicateBookmark` は次の手順で作成します。
> ※ 作成画面で表示されるアクセス許可は変更せず、作成します。

### ステートマシン定義（初版）

```json
{
  "StartAt": "CheckDuplicate",
  "States": {
    "CheckDuplicate": {
      "Type": "Task",
      "Resource": "arn:aws:states:::lambda:invoke",
      "Parameters": {
        "FunctionName": "CheckDuplicateBookmark",
        "Payload.$": "$"
      },
      "ResultPath": "$.duplicateResult",
      "Next": "IsDuplicate?"
    },
    "IsDuplicate?": {
      "Type": "Choice",
      "Choices": [
        {
          "Variable": "$.duplicateResult.Payload.isDuplicate",
          "BooleanEquals": true,
          "Next": "EndDuplicate"
        }
      ],
      "Default": "RequestApproval"
    },
    "EndDuplicate": {
      "Type": "Fail",
      "Error": "DuplicateBookmark",
      "Cause": "Bookmark already exists"
    },
    "RequestApproval": {
      "Type": "Pass",
      "End": true
    }
  }
}
```

⑤ 先ほどダミー設定をしていた EventBridge のルールのターゲットを修正します。EventBridge のルール画面を表示し、作成済のルールを編集します。

⑥ ターゲットタイプ：Step Functions のステートマシンを設定し、作成済のステートマシンを設定、ルールを更新します。

⑦ `CheckDuplicateBookmark` Lambda 関数を作成します。これは登録するブックマークがすでに登録されているかを判定する関数で、判定結果の真偽値のみ返します。

| 項目 | 値 |
|------|-----|
| 関数名 | CheckDuplicateBookmark（Step Functions で設定した名前と一致していること） |
| ランタイム | Python 3.12 |
| アクセス許可 | インラインポリシー作成 |

### インラインポリシー

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "dynamodb:Query",
        "dynamodb:Scan"
      ],
      "Resource": "arn:aws:dynamodb:ap-northeast-1:*:table/テーブル名"
    }
  ]
}
```

### CheckDuplicateBookmark 関数コード

```python
import boto3

dynamodb = boto3.resource("dynamodb")
table = dynamodb.Table("テーブル名")

def lambda_handler(event, context):
    """
    event は EventBridge 由来の入力をそのまま受け取る
    Step Functions からは Payload.$ = "$" で渡される前提
    """
    # EventBridge → detail → content
    content = event.get("detail", {}).get("content")

    if not content:
        # 判定不能だが「重複ではない」として先に進める
        return {
            "isDuplicate": False,
            "reason": "content missing"
        }

    response = table.scan(
        FilterExpression="content = :content",
        ExpressionAttributeValues={
            ":content": content
        }
    )

    return {
        "isDuplicate": response["Count"] > 0
    }
```

⑧ メール送信のため SNS を設定します。Amazon SNS の画面から「トピックの作成」へ進みます。

⑨ タイプ：スタンダード、名前：`BookmarkNotification` としトピック作成します。

⑩ 自身のメールアドレスでサブスクリプションを作成し、受信したメールから承認を行います。Topic の ARN を控えておいてください。

⑪ 承認メール送信 Lambda 関数を作成します。

|------|-----|
| 関数名 | SendApprovalMail |
| ポリシー | インラインポリシー追加（Topic の ARN は置き換えること） |

> ※ Topic の ARN は置き換えること
> ※ `approve_url` はダミーです。後ほど修正します。

### インラインポリシー

```json
    }

```

### SendApprovalMail 関数コード

```python
import json
import boto3
import urllib.parse

sns = boto3.client("sns")
TOPIC_ARN = "arn:aws:sns:ap-northeast-1:xxxxxxxxxxxx:BookmarkNotification"

def lambda_handler(event, context):
    task_token = event["TaskToken"]
    detail = event["detail"]

    approve_url = (
        "https://example.com/approve?"
        + urllib.parse.urlencode({"token": task_token})
    )

    message = f"""
Bookmark approval required.

Title: {detail.get('title')}
URL: {detail.get('content')}

Approve:
{approve_url}
"""

    sns.publish(
        TopicArn=TOPIC_ARN,
        Subject="Bookmark Approval Required",
        Message=message
    )

    return {}
```

⑬ Callback 受信用の Lambda 関数を作成します。これはメールリンクから人間による承認操作を Step Functions に伝えるための関数です。

| 項目 | 値 |
|------|-----|
| 関数名 | ApprovalCallback |

### インラインポリシー

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "states:SendTaskSuccess",
        "states:SendTaskFailure"
      ],
      "Resource": "*"
    }
  ]
}
```

### ApprovalCallback 関数コード

```python
import json
import boto3
import urllib.parse

sf = boto3.client("stepfunctions")

def lambda_handler(event, context):
    try:
        # ===== クエリパラメータ取得（HTTP API v2 対応）=====
        params = event.get("queryStringParameters") or {}
        task_token = params.get("token")
        action = params.get("result", "approve")

        if not task_token:
            raise Exception("taskToken is missing")

        # URL デコード（必須）
        task_token = urllib.parse.unquote(task_token)

        if action == "approve":
            sf.send_task_success(
                taskToken=task_token,
                output=json.dumps({"approved": True})
            )
        else:
            sf.send_task_failure(
                taskToken=task_token,
                error="Rejected",
                cause="Rejected by reviewer"
            )

        return {
            "statusCode": 200,
            "body": "Approval processed successfully"
        }

    except Exception as e:
        print("ERROR:", str(e))
        return {
            "statusCode": 500,
            "body": json.dumps({"message": "Internal Server Error"})
        }
```
