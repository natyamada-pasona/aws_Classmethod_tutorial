# Bookmark 承認ワークフロー 構成図

## Step 1：タスク1〜4 完了時点（基本の投稿機能）

利用者が Web UI からブックマークを投稿し、API Gateway → Lambda → DynamoDB に保存される最小構成。

```mermaid
graph LR
    User(("👤 利用者"))
    UI["Web UI<br/>(index.html)"]
    APIGW["API Gateway<br/>POST /bookmarks"]
    Lambda["Lambda<br/>CreateBookmark"]
    DDB[("DynamoDB<br/>BookmarksTable")]

    User --> UI --> APIGW --> Lambda --> DDB

    style User fill:#4a90d9,color:#fff,stroke:none
    style APIGW fill:#8b5cf6,color:#fff,stroke:none
    style Lambda fill:#f59e0b,color:#fff,stroke:none
    style DDB fill:#3b82f6,color:#fff,stroke:none
```

---

## Step 2：タスク5 完了時点（EventBridge 連携）

投稿時に `shared=true` の場合、Lambda が EventBridge にイベントを送信。ルールでイベントを検知する仕組みが追加される。

```mermaid
graph LR
    User(("👤 利用者"))
    UI["Web UI"]
    APIGW["API Gateway<br/>POST /bookmarks"]
    Lambda["Lambda<br/>CreateBookmark"]
    DDB[("DynamoDB<br/>BookmarksTable")]
    EB["EventBridge<br/>bookmarks-bus"]
    Rule["ルール<br/>BookmarkCreatedRule"]
    Target["ターゲット<br/>（次ステップで設定）"]

    User --> UI --> APIGW --> Lambda --> DDB
    Lambda -.->|shared=true| EB --> Rule --> Target

    style User fill:#4a90d9,color:#fff,stroke:none
    style APIGW fill:#8b5cf6,color:#fff,stroke:none
    style Lambda fill:#f59e0b,color:#fff,stroke:none
    style DDB fill:#3b82f6,color:#fff,stroke:none
    style EB fill:#e11d48,color:#fff,stroke:none
    style Rule fill:#e11d48,color:#fff,stroke:none
    style Target fill:#6b7280,color:#fff,stroke:none
```

---

## Step 3：タスク6 完了時点（全体構成）

Step Functions による承認ワークフローが完成。重複チェック → 承認メール送信 → 人手承認のフルフローが動作する。

```mermaid
graph LR
    User(("👤 利用者"))
    UI["Web UI"]
    APIGW1["API Gateway<br/>POST /bookmarks"]
    CreateBM["Lambda<br/>CreateBookmark"]
    DDB[("DynamoDB<br/>BookmarksTable")]
    EB["EventBridge<br/>bookmarks-bus"]
    Rule["ルール"]

    subgraph SFN["Step Functions（承認ワークフロー）"]
        CheckDup["Lambda<br/>CheckDuplicate"]
        SendMail["Lambda<br/>SendApprovalMail"]
    end

    SNS["SNS<br/>BookmarkNotification"]
    Manager(("👤 承認者"))
    APIGW2["API Gateway<br/>GET /approve"]
    Callback["Lambda<br/>ApprovalCallback"]

    User --> UI --> APIGW1 --> CreateBM --> DDB
    CreateBM -.->|shared=true| EB --> Rule --> SFN
    CheckDup --> DDB
    SendMail --> SNS -->|承認依頼メール| Manager
    Manager -->|承認リンク| APIGW2 --> Callback -->|SendTaskSuccess| SFN

    style User fill:#4a90d9,color:#fff,stroke:none
```
