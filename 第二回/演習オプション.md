# オプション演習＜発展編＞ AWS Step Functions を使用したワークフローオーケストレーション

## 概要

本演習では、サーバーレスで構築されたブックマーク共有アプリケーションを題材にします。
このアプリケーションでは、利用者が有用な Web リソース（URL）を投稿し、社内でのナレッジ共有を目的としています。

### 背景・課題

アプリケーションの利用拡大に伴い、以下のような課題が顕在化しています。

- 投稿数の増加により、手動レビューの負荷が急増
- 重複した URL や不適切な投稿が混在する可能性
- 投稿がコンテスト対象になるかどうかの判断が必要

すべてを自動化するにはリスクが高く、最終判断は人が行いたいと考えています。
マネージャーはこれらの課題を踏まえ、可能な限り **自動評価でスケールさせつつ、最終的な公開判断は人手承認として残す** という、現実的で運用しやすいプロセスを求めています。

### 構築する投稿処理フロー

1. 利用者が Web UI からブックマークを投稿
2. 投稿内容がイベントとしてシステム内部に伝播
3. 自動チェック処理を実行
   - URL の重複チェック
   - 投稿内容の妥当性評価
4. 自動処理だけでは判断できない場合は人手による承認ステップへ移行
5. マネージャーがメールリンクから承認／却下を実施

## タスク２：Lambda 関数作成（CreateBookmark）

① Lambda コンソール画面で関数名 `CreateBookmark`、ランタイム `Python 3.12` で関数を作成します。

② `CreateBookmark` 関数の実行ロールのリンクから以下のポリシーを確認・追加します。

- `AWSLambdaBasicExecutionRole`（CloudWatch 用。存在することを確認）
- インラインポリシー追加（DynamoDB 操作用）※ アカウント ID、テーブル名は置き換え

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "dynamodb:PutItem"
      ],
      "Resource": "arn:aws:dynamodb:ap-northeast-1:＜アカウントID＞:table/BookmarksTable"
    }
  ]
}
```

③ コードは以下の通りです。

> 初回の Lambda は成功し DynamoDB への PUT が成功、2回目以降は同じデータが PUT されることとなり 409 エラーとなります。

```python
import json
import boto3
from botocore.exceptions import ClientError

dynamodb = boto3.resource("dynamodb")
table = dynamodb.Table("BookmarksTable")

def lambda_handler(event, context):
    body = json.loads(event["body"])
    content = body["content"]
    title = body.get("title", "")
    shared = body.get("shared", False)

    try:
        table.put_item(
            Item={
                "content": content,
                "title": title,
                "shared": shared
            },
            ConditionExpression="attribute_not_exists(content)"
        )
    except ClientError as e:
        if e.response["Error"]["Code"] == "ConditionalCheckFailedException":
            return {
                "statusCode": 409,
                "body": json.dumps({"message": "Duplicate bookmark"})
            }
        raise

    return {
        "statusCode": 200,
        "headers": {
            "Access-Control-Allow-Origin": "*",
            "Access-Control-Allow-Headers": "Content-Type",
            "Access-Control-Allow-Methods": "OPTIONS,POST"
        },
        "body": json.dumps({"message": "Bookmark created successfully!"})
    }
```


## タスク５：EventBridge 設定

Lambda が「Bookmark が投稿された」という事実を EventBridge に送信し、EventBridge のルールでその事実を検知したら Step Functions（ワークフロー）を起動できる状態にします。
EventBridge では演習専用のカスタムイベントバスを作成します。

① EventBridge の画面を表示し、左側のメニューから「イベントバス」を選択、カスタムイベントバス欄の「イベントバスを作成」をクリックします。

② 名前を `bookmarks-bus` に設定し作成します。

③ Lambda の編集をします。Lambda 関数に設定されている既存ロールに以下インラインポリシーを追加し、Lambda が EventBridge に PutEvents できるよう設定します。

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": "events:PutEvents",
      "Resource": "arn:aws:events:ap-northeast-1:*:event-bus/bookmarks-bus"
    }
  ]
}
```

④ Lambda コードも以下に編集し、EventBridge へ送信できるようにします。バス名は作成した EventBridge カスタムイベントバス名に置き換えること。

```python
import json
import boto3
from botocore.exceptions import ClientError

dynamodb = boto3.resource("dynamodb")
table = dynamodb.Table("BookmarksTable")

# ★追加: EventBridge クライアント
eventbridge = boto3.client("events")

def lambda_handler(event, context):
    body = json.loads(event["body"])
    content = body["content"]
    title = body.get("title", "")
    shared = body.get("shared", False)

    try:
        table.put_item(
            Item={
                "content": content,
                "title": title,
                "shared": shared
            },
            ConditionExpression="attribute_not_exists(content)"
        )
    except ClientError as e:
        if e.response["Error"]["Code"] == "ConditionalCheckFailedException":
            return {
                "statusCode": 409,
                "body": json.dumps({"message": "Duplicate bookmark"})
            }
        raise

    # ★保存成功後のみ、shared=true ならイベント送信
    if shared:
        response = eventbridge.put_events(
            Entries=[
                {
                    "EventBusName": "bookmarks-bus",
                    "Source": "bookmark.app",
                    "DetailType": "BookmarkShared",
                    "Detail": json.dumps({
                        "content": content,
                        "title": title,
                        "shared": shared
                    })
                }
            ]
        )
        # ★追加: EventBridge 送信成功ログを CloudWatch Logs 出力
        print("Event sent to EventBridge")
        print("EventBridge response:", response)

    return {
        "statusCode": 200,
        "headers": {
            "Access-Control-Allow-Origin": "*",
            "Access-Control-Allow-Headers": "Content-Type",
            "Access-Control-Allow-Methods": "OPTIONS,POST"
        },
        "body": json.dumps({"message": "Bookmark created successfully!"})
    }
```

EventBridge に「BookmarkCreated」という事実が伝わり、次に業務フローを Step Functions によって制御します。条件によって処理を分岐し、人の手による承認作業および結果確定を実現し、流れを可視化します。

① Step Functions の画面を表示し、これまで利用していたリージョンになっていることを確認します。

⑥ ターゲットタイプ：Step Functions のステートマシンを設定し、作成済のステートマシンを設定、ルールを更新します。

⑦ `CheckDuplicateBookmark` Lambda 関数を作成します。これは登録するブックマークがすでに登録されているかを判定する関数で、判定結果の真偽値のみ返します。

| 項目 | 値 |
|---|---|
| 関数名 | `CheckDuplicateBookmark`（Step Functions で設定した名前と一致していること） |
| ランタイム | Python 3.12 |
| アクセス許可 | インラインポリシー作成 |

インラインポリシー：

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "dynamodb:Query",
        "dynamodb:Scan"
      ],
      "Resource": "arn:aws:dynamodb:ap-northeast-1:*:table/BookmarksTable"
    }
  ]
}
```

コード：

```python
import boto3

dynamodb = boto3.resource("dynamodb")
table = dynamodb.Table("BookmarksTable")

def lambda_handler(event, context):
    """
    event は EventBridge 由来の入力をそのまま受け取る
    Step Functions からは Payload.$ = "$" で渡される前提
    """
    # EventBridge → detail → content
    content = event.get("detail", {}).get("content")

    if not content:
        # 判定不能だが「重複ではない」として先に進める
        return {
            "isDuplicate": False,
            "reason": "content missing"
        }

    response = table.scan(
        FilterExpression="content = :content",
        ExpressionAttributeValues={
            ":content": content
        }
    )

    # CreateBookmark で既に1件保存済みのため、2件以上で重複と判定
    return {
        "isDuplicate": response["Count"] > 1
    }
```

```python
import json
import boto3
import urllib.parse

sns = boto3.client("sns")
TOPIC_ARN = "arn:aws:sns:ap-northeast-1:xxxxxxxxxxxx:BookmarkNotification"

def lambda_handler(event, context):
    task_token = event["TaskToken"]
    detail = event["detail"]

    approve_url = (
        "https://example.com/approve?"
        + urllib.parse.urlencode({"token": task_token})
    )

    message = f"""
Bookmark approval required.

Title: {detail.get('title')}
URL: {detail.get('content')}

Approve:
{approve_url}
"""

    sns.publish(
        TopicArn=TOPIC_ARN,
        Subject="Bookmark Approval Required",
        Message=message
    )

    return {}
```

⑬ Callback 受信用の Lambda 関数を作成します。これはメールリンクから人間による承認操作を Step Functions に伝えるための関数です。

| 項目 | 値 |
|---|---|
| 関数名 | `ApprovalCallback` |

インラインポリシー追加：

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "states:SendTaskSuccess",
        "states:SendTaskFailure"
      ],
      "Resource": "*"
    }
  ]
}
```

コード：

```python
import json
import boto3
import urllib.parse

sf = boto3.client("stepfunctions")

def lambda_handler(event, context):
    try:
        # クエリパラメータ取得（HTTP API v2 対応）
        params = event.get("queryStringParameters") or {}
        task_token = params.get("token")
        action = params.get("result", "approve")

        if not task_token:
            raise Exception("taskToken is missing")

        # URL デコード（必須）
        task_token = urllib.parse.unquote(task_token)

        if action == "approve":
            sf.send_task_success(
                taskToken=task_token,
                output=json.dumps({"approved": True})
            )
        else:
            sf.send_task_failure(
                taskToken=task_token,
                error="Rejected",
                cause="Rejected by reviewer"
            )

        return {
            "statusCode": 200,
            "body": "Approval processed successfully"
        }
    except Exception as e:
        print("ERROR:", str(e))
        return {
            "statusCode": 500,
            "body": json.dumps({"message": "Internal Server Error"})
        }
```
