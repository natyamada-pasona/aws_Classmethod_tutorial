# コマンドメモ

## AWS プロファイル追加

```bash
aws configure --profile <プロファイル名>
# 設定確認
aws sts get-caller-identity --profile <プロファイル名>
```

SSO の場合

```bash
aws configure sso --profile <プロファイル名>
```

## AWS プロファイル削除（手動）

AWS CLI にはプロファイルを丸ごと削除するコマンドがないため、設定ファイルを直接編集する。

```bash
# credentials から該当プロファイルのセクションを削除
vim ~/.aws/credentials

# config から該当プロファイルのセクションを削除
vim ~/.aws/config
```

### タスク5：CDK プロジェクト作成 & デプロイ

```bash

# デプロイ
make deploy
```
